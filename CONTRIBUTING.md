# Guidelines for Hacktoberfest 2026 contributors

* Preview changes in your favorite modern Web browser, such as Mozilla Firefox.
* Avoid using characters added in the very latest version of Unicode 
(specifically Unicode 18.0.0 as of the start of Hacktoberfest 2026) since device 
manufacturers might not have caught up yet.
